Ποιος λειτουργεί την ιστοσελίδα

Αυτή είναι η ιστοσελίδα TallyoraLabs για LUMENFOLD: Pocket Worlds και Wonderleaf, με υπεύθυνο τον Στυλιανό Μήνογλου, Ελλάδα. Επικοινωνία: tallyoralabs@gmail.com.

Φιλοξενία και τεχνικά δεδομένα

Η ιστοσελίδα φιλοξενείται στο GitHub Pages. Το GitHub καταγράφει διευθύνσεις IP επισκεπτών για ασφάλεια, ακόμη και χωρίς σύνδεση σε λογαριασμό GitHub. Δείτε την πολιτική απορρήτου GitHub για τις δικές του πρακτικές επεξεργασίας και διατήρησης.

Χωρίς διαφημίσεις ή analytics επισκεπτών

Η ιστοσελίδα δεν περιλαμβάνει διαφημίσεις, analytics, tracking pixels, εξωτερικές γραμματοσειρές ή ενσωματωμένα social widgets. Δεν ορίζει cookies ούτε αποθηκεύει προτιμήσεις επισκεπτών. Η γλώσσα αλλάζει με απλούς συνδέσμους μεταξύ ελληνικών και αγγλικών σελίδων.

Επικοινωνία και διαγραφή

Οι σύνδεσμοι email ανοίγουν την εφαρμογή αλληλογραφίας σας. Δεν στέλνεται μήνυμα αυτόματα ούτε υποβάλλονται στοιχεία στην ιστοσελίδα. Εάν στείλετε email, λαμβάνουμε τη διεύθυνση και το περιεχόμενο, τα χρησιμοποιούμε για το αίτημα και κρατάμε τη σχετική αλληλογραφία όσο χρειάζεται. Για θέματα παιδιών επικοινωνεί γονέας ή κηδεμόνας χωρίς περιττά αναγνωριστικά στοιχεία.

Επιλογές σας

Όλες οι σελίδες διαβάζονται χωρίς λογαριασμό. Επικοινωνήστε για ερωτήσεις, διόρθωση ή διαγραφή πληροφοριών που έχετε στείλει με email. Για δεδομένα εφαρμογής, δείτε τις ξεχωριστές πολιτικές και σελίδες διαγραφής LUMENFOLD και Wonderleaf.

Δικαιώματα και email υποστήριξης

Όπου εφαρμόζεται, μπορείτε να ζητήσετε πρόσβαση, διόρθωση, διαγραφή, περιορισμό ή φορητότητα προσωπικών δεδομένων και να αντιταχθείτε σε επεξεργασία βάσει έννομων συμφερόντων. Επικοινωνήστε στο tallyoralabs@gmail.com. Μπορείτε να υποβάλετε καταγγελία στην αρμόδια αρχή, συμπεριλαμβανομένης της Αρχής Προστασίας Δεδομένων Προσωπικού Χαρακτήρα στην Ελλάδα. Δείτε την ενημέρωση της Ευρωπαϊκής Επιτροπής για τα δικαιώματα. Η υποστήριξη χρησιμοποιεί Gmail (Google)· η υποδομή του μπορεί να επεξεργάζεται δεδομένα διεθνώς με τις εγγυήσεις της πολιτικής απορρήτου Google. Τα μηνύματα χρησιμοποιούνται για το αίτημα και την ασφάλεια αλληλογραφίας, όχι για ανεπιθύμητη διαφήμιση.
