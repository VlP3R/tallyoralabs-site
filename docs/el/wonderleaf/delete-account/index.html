Wonderleaf

Διαγραφή δεδομένων Wonderleaf

Τελευταία ενημέρωση: 2 Νοεμβρίου 2026

Η τρέχουσα εφαρμογή Android Wonderleaf δεν έχει online λογαριασμό. Πρόοδος ανάγνωσης, αγαπημένα και προτιμήσεις αποθηκεύονται μόνο στη συσκευή.

Εκκαθάριση στη συσκευή

Ενήλικας μπορεί να ανοίξει Ρυθμίσεις Android → Εφαρμογές → Wonderleaf → Αποθήκευση (ή Αποθήκευση και cache) → Εκκαθάριση αποθήκευσης / δεδομένων. Η ονομασία διαφέρει ανά συσκευή. Επαναφέρονται πρόοδος, αγαπημένα, γλώσσα και προτιμήσεις. Η απεγκατάσταση αφαιρεί επίσης τα τοπικά δεδομένα· το cloud backup είναι απενεργοποιημένο για το Wonderleaf.

Χωρίς λογαριασμό server προς διαγραφή

Δεν υπάρχει λογαριασμός ανάγνωσης Wonderleaf ή παιδικό προφίλ σε server στην τρέχουσα έκδοση. Δεν μπορούμε να προσπελάσουμε ή να διαγράψουμε εξ αποστάσεως την τοπική πρόοδο της συσκευής.

Διαγραφή αλληλογραφίας υποστήριξης

Γονέας ή κηδεμόνας μπορεί να στείλει στο tallyoralabs@gmail.com με θέμα Wonderleaf data deletion για πληροφορίες που είχε ήδη στείλει στην υποστήριξη. Στείλτε από την ίδια διεύθυνση. Μη συμπεριλάβετε όνομα ή άλλα αναγνωριστικά παιδιού. Ελέγχουμε το αίτημα και εξηγούμε τυχόν συγκεκριμένη νόμιμη υποχρέωση διατήρησης πριν επιβεβαιώσουμε το αποτέλεσμα.
